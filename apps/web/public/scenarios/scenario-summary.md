# UI/UX 시나리오 핵심 요약본

## 🎨 시나리오 A : 레퍼런스 보고 만들기

> **개념:** 소상공인이 기존에 잘 만들어진 디자인 에셋(시안)을 먼저 탐색하고, 마음에 드는 스타일을 기반으로 광고 콘텐츠를 빌드업하는 플로우
> 

### 📱 화면별 이미지 구조 및 유저 시나리오

- **1번 화면 (홈 / 시작 화면):** * **구조:** 상단에 브랜드 슬로건 및 마스코트 캐릭터가 배치되어 있으며, 하단에 3가지 진입 모드가 세로형 큰 버튼 카드로 구성됨.
    - **시나리오:** 사용자가 첫 번째 메뉴인 `[레퍼런스 보고 만들기 (마음에 드는 광고 스타일을 골라보세요)]` 카드를 선택하여 진입합니다.
- **2번 화면 (찰떡 광고 샘플 갤러리):**
    - **구조:** 상단에 키워드 검색창과 업종별 카테고리 태그 칩(`전체`, `카페`, `음식점`, `뷰티`, `포스터`)이 있고, 하단에는 격자형(Grid)으로 고퀄리티 실제 광고 포스터 에셋들이 나열됨.
    - **시나리오:** 사장님이 카테고리를 필터링하여 자신의 가게 분위기와 어울리는 `[감성 카페 포스터 (딸기라떼 시안)]` 예시를 선택합니다.
- **3번 화면 (찰떡 스튜디오 - AI 대화형 브리프):**
    - **구조:** 상단에 2번 단계에서 선택한 레퍼런스 이미지가 미니 카드로 고정 노출됨. 중앙에는 AI 챗봇과의 메신저 대화창 인터페이스가 펼쳐지며, 하단에는 빠른 입력을 돕는 다지선다 답변 칩(`카페`, `음식점`, `디저트`)과 자유 텍스트 입력창, 그리고 `정보 입력 1/5` 형태의 프로그레스 바가 제공됨.
    - **시나리오:** AI 챗봇이 "이 스타일을 참고해서 광고를 만들어줄게요. 어떤 가게인가요?"라고 질문하면, 사장님은 추천 버튼을 툭툭 누르거나 하단 검색창에 추가 맥락을 입력하며 대화식으로 부족한 정보(HITL 루프)를 채워나갑니다.
- **4번 화면 (찰떡 광고 시안 결과):**
    - **구조:** AI가 최종 생성해낸 4분할 광고 포스터 시안이 메인에 노출됨. 하단에는 1단계 편집을 위한 퀵 피드백 버튼(`문구 더 짧게`, `상품 대 크게`, `핑크톤 줄이기`)과 `[선택한 시안 편집하기]` 액션 버튼이 배치됨.
    - **시나리오:** 사장님은 완성된 4개의 고퀄리티 시안 중 가장 마음에 드는 것을 고르고, 아쉬운 부분은 하단 버튼이나 채팅을 통해 2차 피드백 루프를 돌려 수정합니다.

## 📸 시나리오 B : 내 사진으로 만들기

> **개념:** 스마트폰으로 대충 찍은 우리 가게 제품/매장 사진을 업로드하면, VLM이 시각적 특징을 자동 추출하고 사용자가 카피와 레이아웃 세부 조건을 제안받아 완성하는 보존형 합성 플로우
> 

### 📱 화면별 이미지 구조 및 유저 시나리오

- **1번 화면 (사진 업로드):**
    - **구조:** 중앙에 거대한 연두색 파일 드롭존(`사진을 끌어오거나 클릭해서 선택하세요`)이 있고, 아래에 사진 가이드 태그와 최근 업로드된 사진 목록, 그리고 백엔드 분석 진행률을 보여주는 프로그레스 바(`AI가 사진을 분석하고 있어요 68%`)가 위치함.
    - **시나리오:** 사용자가 `[내 사진으로 만들기]` 모드로 진입해 가게의 딸기라떼 음료 사진을 업로드하고 `[다음 단계로]`를 누릅니다.
- **2번 화면 (AI가 사진을 분석하고 제안해요):**
    - **구조:** 좌상단에 업로드된 사진과 함께 VLM 분석 결과(`딸기라떼 음료`, `밝은 자연광`, `핑크·크림톤`)가 텍스트 래핑으로 명시됨. 하단에는 AI가 제안하는 마케팅 목적 선택 칩(`신메뉴 출시`, `시즌 한정 메뉴`, `할인 이벤트`)과 `[직접 원하는 방향을 입력할 수도 있어요]`라는 자유 프롬프트 인풋창이 공존함.
    - **시나리오:** AI가 내 사진의 시각적 특징을 정확히 짚어낸 것을 눈으로 확인한 후, 이번 광고의 목적(예: `[신메뉴 출시]`)을 고르거나 하단 창에 자유 요구사항을 적어 프롬프트 자유도를 챙깁니다.
- **3번 화면 (문구와 분위기를 선택해요):**
    - **구조:** 상단에 AI가 찰떡같이 자동 생성해준 마케팅 카피 후보 3가지(체크박스 형태)가 노출됨. 그 아래로 분위기 태그(`감성적인`, `상품성`, `고급스러운`) 및 타겟 채널/사이즈 버튼(`인스타 피드 1:1`, `인스타 스토리 9:16`)이 매끄럽게 배열됨.
    - **시나리오:** 사장님은 AI가 제안한 기가 막힌 추천 문구 중 마음에 드는 항목을 '체크(V)'하고, 원하는 포스터 사이즈를 골라 `[브리프 확인하기]`를 누릅니다. (입력 피로도 최소화)
- **4번 화면 (AI가 브리프를 정리했어요):**
    - **구조:** 최종 생성 전 단계로, 백엔드의 `MarketingState` 구조체를 투명하게 시각화한 '광고 브리프 요약 표'가 정돈되어 나타남. (`광고 목적`, `상품/서비스`, `선택한 문구`, `분위기`, `사용 채널`, `핵심 색상` 등)
    - **시나리오:** 내가 수락한 마케팅 문맥 정보를 최종 확인(Confirm)한 뒤, `[찰떡 광고 생성하기 ✨]` 버튼을 눌러 원본 제품 픽셀이 완벽히 보존된 고품질 인페인팅 광고 포스터를 추출합니다.

## 💬 시나리오 C : 대화로 시작하기 (T2I 중심)

> **개념:** 사진이나 고정된 템플릿 없이, 백지상태에서 사장님의 개떡 같은 한 줄 문장만으로 인텐트를 파싱해 완벽한 마케팅 광고 에셋을 무에서 유로 창조하는 플로우
> 

### 📱 화면별 이미지 구조 및 유저 시나리오

- **1번 화면 (대화로 시작하기 - 홈):**
    - **구조:** 중앙에 `원하는 광고를 편하게 적어보세요`라는 안내와 함께 텍스트 입력 검색창이 크게 자리 잡고 있음. 바로 위아래로 소상공인들이 참고하기 좋은 예시 문장 카드들(`우리 카페 딸기라떼...`, `삼겹살집 회식 손님...`)과 빠른 시작 업종 칩들이 입력을 보조함.
    - **시나리오:** 사용자가 `[대화로 시작하기]`로 진입해 하단 창에 자유롭게 **"우리 가게 광고 좀 멋지게 만들어줘"** 혹은 구체적인 한 줄을 입력한 뒤 전송합니다. (자유도 100%)
- **2번 화면 (AI가 의도를 파악하고 질문해요):**
    - **구조:** 상단에 AI가 유저의 첫 문장에서 발라낸 `파악한 내용(업종: 카페, 상품: 딸기라떼, 광고목적: 신메뉴 출시)`이 보라색 박스 안에 깔끔하게 정리되어 노출됨. 하단에는 백엔드 `Validator`가 누락되었다고 판단한 부족한 컨텍스트(예: 분위기)를 채우기 위한 동적 질문 카드와 버튼 칩들이 나타남.
    - **시나리오:** AI가 "이만큼은 이해했어요! 더 잘 맞는 광고를 위해 아래 정보(분위기)를 조금만 알려주세요"라고 인터럽트를 걸면, 사용자는 `[감성적인]` 같은 칩을 눌러 누락된 컨텍스트 변수를 실시간 핑퐁으로 채워줍니다.
- **3번 화면 (문구와 채널을 선택해요):**
    - **구조:** 수집된 7대 컨텍스트를 바탕으로 LLM이 실시간 빌딩해낸 추천 마케팅 카피 리스트가 상단에 배치되고, 하단에는 결과물 규격(인스타 피드, 스토리, 전단지 A4 등) 선택창과 `정보 입력 3/4` 가변 프로그레스 바가 보임.
    - **시나리오:** 사장님은 생성된 타겟 맞춤형 카피 중 하나를 픽(Pick)하고, 인쇄용인지 SNS 업로드용인지 채널을 최종 선택합니다.
- **4번 화면 (브리프를 확인하고 생성해요):**
    - **구조:** 시나리오 B의 최종 화면과 유사하나, 하단에 `[✨ 추천 이미지 방향]`이라는 항목이 추가되어 백엔드 `Refactoring Node`가 설계한 영문 SOP 프롬프트(`subject`, `lighting`, `composition`)의 핵심 무드를 소상공인이 읽기 쉬운 한국어 자연수로 풀어내어 보여줌.
    - **시나리오:** 사장님은 "크림톤 배경에 딸기라떼를 중앙에 배치하겠구나" 하고 AI가 그릴 이미지의 방향성을 미리 신뢰감 있게 확인한 후, `[찰떡 광고 생성하기]` 버튼을 눌러 최종 아웃풋을 뽑아냅니다.
