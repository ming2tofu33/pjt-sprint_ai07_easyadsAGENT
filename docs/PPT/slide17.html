01
WHAT WE BUILT
주요 성과
데모 이미지를 한 번 만드는 수준을 넘어, 대화형 광고 생성 서비스의 기본 흐름을 연결했습니다.
1
대화형 광고 생성 MVP자연어 입력을 상품, 업종, 목적, 톤, 채널 정보로 구조화
2
E2E 생성 파이프라인입력 이해 → 카피 결정 → 이미지 생성 → 검증 → 저장
3
상태 기반 생성 구조LangGraph와 MarketingState로 질문, 선택, 생성, 재개 관리
4
검증 기반 마련Compliance Gate, Quality Gate, Eval Layer, 테스트 기반 구축
02
CURRENT LIMITS
현재 한계
서비스 파이프라인은 연결했지만, 실제 제품 수준으로 안정화하려면 아직 남은 변수가 있습니다.
1
생성 품질 의존성모델과 입력 이미지 품질에 따라 결과 편차 발생 가능
2
광고 검토의 보조적 한계Compliance Gate는 법률 자문이 아닌 위험 문구 완화 장치
3
업종·상품 커버리지Domain Routing SSOT와 Rule Pack 고도화 필요
4
운영 환경 대응비용, 지연 시간, 모델 장애 대응 체계 추가 필요
03
NEXT TASKS
향후 과제
다음 단계는 더 많은 기능보다, 실제 운영에서 흔들리지 않는 품질과 기준을 만드는 일입니다.
1
생성 품질 안정화모델과 입력 이미지 품질에 따른 결과 편차 개선
2
광고 검토 기준 고도화Compliance Rule Pack과 안전 문구 제안 기준 정교화
3
업종·상품 대응 확장Domain Routing SSOT 고도화로 다양한 광고 상황 대응
4
운영 지표 관리비용, 지연 시간, 모델 장애, 실제 로그 기반 정량 지표 관리
CONCLUSION
개떡찰떡은 단순 이미지 생성 데모가 아니라, 모호한 요청을 광고 제작 정보로 바꾸고 생성·검증·저장·재개까지 연결한 대화형 AI 광고 제작 MVP입니다.
