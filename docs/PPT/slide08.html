LANGGRAPH 구성과 역할
Node · Edge · Conditional Edge · Interrupt / Resume · Control
Node
입력 분석, 질문, 카피 생성, 레이아웃 계획, 이미지 생성, 검증 작업 단위
Edge
Node와 Node 사이의 실행 순서와 다음 단계를 연결
Conditional
정보 부족, 검증 실패, 사용자 선택 여부에 따른 조건 분기
Interrupt
응답이 필요한 지점에서 멈추고, 응답 후 같은 흐름으로 재개
Control
수정이 필요한 경우 특정 단계부터 다시 실행
AGENT EXECUTION STRUCTURE
LangGraph는 개떡찰떡이
광고 제작 에이전트처럼 행동하게 합니다
사용자 입력 분석, 부족 정보 질문, 카피 결정, 레이아웃 계획, 이미지 생성, 검증 흐름을 하나의 실행 그래프로 관리합니다.
LangGraph는 광고 생성 과정을 Node와 Edge로 나누고, 질문 · 판단 · 생성 · 검증 흐름을 제어하는 에이전트 실행 구조입니다
