INTERRUPT / RESUME

RETRY CONTROL
검증 실패 시 전체가 아니라 필요한 단계부터 다시 실행합니다.
입력 분석 → 질문 → 생성 → 검증 → 저장을 하나의 상태 그래프로 제어
STATE

LANGGRAPH 구성과 역할
Node
입력 분석, 질문, 생성, 검증 같은 작업 단위
Edge
Node 사이의 실행 순서와 다음 단계를 연결
Conditional
정보 부족, 검증 실패, 사용자 선택에 따른 분기
Interrupt
사용자 응답이 필요한 지점에서 멈추고 재개
Control
수정이 필요한 경우 특정 단계부터 다시 실행
LangGraph는 광고 생성 과정을 Node와 Edge로 나누고, 질문 · 판단 · 생성 · 검증 흐름을 제어하는 에이전트 실행 구조입니다
