01
REQUEST IS NOT COPY
요청문은 카피가 아닙니다
“홍보하고 싶어”, “광고 만들어줘”는 사용자의 의도입니다. 광고 이미지에 들어갈 문구는 별도로 확정된 표시 문구만 사용합니다.
요청문 분리 예시
“손님 많이 오게 해줘” → 광고 문구 아님
“트러플 감자튀김 문의하기” → 확정된 표시 문구
02
EVIDENCE + DOMAIN
근거와 도메인 위에서 씁니다
상품 정보, 이미지 관찰, 도메인 라우팅을 함께 보고 카피 방향을 정합니다. 업종명만 보고 가격·효능·전문성·혜택을 단정하지 않습니다.
카피 판단 재료
Evidence 확인된 사실
Product 시각 맥락
Domain 업종 정책
Display 실제 표시 문구
03
FAIL-CLOSED
불확실하면 멈춥니다
정보가 부족하거나 상품과 카피 방향이 어긋나면 자동으로 꾸며내지 않습니다. fallback, 추가 질문, 수동 검토로 보내고 lineage를 남깁니다.
