NODE가 STATE를 쓰는 방식
read → work → update
입력 이해
요청에서 상품, 업종, 목적을 추출해 광고 브리프의 시작점을 만듭니다.
카피 결정
브리프와 사용자 선택을 바탕으로 카피 후보와 확정 문구를 저장합니다.
생성 계획
카피와 포맷을 기준으로 슬롯, 프롬프트, 이미지 요청을 구성합니다.
검증 / 결과
생성 결과와 실패 사유를 다시 State에 남겨 재시도와 복구가 가능하게 합니다.
