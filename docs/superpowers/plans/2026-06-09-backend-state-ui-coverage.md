# Backend State UI Coverage Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make UI-visible LangGraph and generation job state survive API boundaries, thread restore, progress display, interrupt handling, and final result review without exposing raw provider internals.

**Architecture:** Treat backend state as a contract, not as an unlimited dump. Persist and expose an explicit UI-safe allowlist, map it through the web API client, restore it into `ChatFlowState`, and render quality/progress/copy/review state in existing generation screens. Raw prompts, provider responses, local file paths, and secrets stay hidden.

**Tech Stack:** Python FastAPI/Pydantic/LangGraph state, Supabase-backed generation jobs and chat snapshots, Next.js/React/Vitest, TypeScript UI contract helpers.

---

## Scope Check

This plan covers the state visibility issues found in the code review:

- Final OCR/quality state is generated by backend but not reflected in result UI.
- Thread snapshot restore loses copy candidate state, selected copy state, origin labels, result payload, and progress.
- Generation progress UI does not use backend `progress_percent` and `message`.
- Generation job interrupts only partially surface backend interrupt metadata.
- Coverage matrices are static and can overstate graph-to-UI coverage.

The open document `docs/광고법 규제 시스템 추가(0609).md` describes a larger compliance gate project. This plan does not implement that backend compliance graph. It only adds a UI-safe `compliance` result payload display hook so future compliance reports can show up in the same review panel.

```ts
export type ValidationFeedbackItem = {
  id: "background" | "safe_area" | "readability" | "final" | "ocr" | "compliance";
  label: string;
  status: ValidationFeedbackStatus;
  message: string;
};

export function buildResultReviewItems(payload: ResultArtifactPayload | null | undefined): ValidationFeedbackItem[] {
  if (!payload) {
    return [];
  }

  const items = buildValidationFeedbackItems(payload.validation_summary ?? null);
  const ocrDecision = safeString(payload.qualityDecision) || safeString((payload.ocr_gate as Record<string, unknown> | null | undefined)?.decision);

  if (payload.qualityRejected || ocrDecision === "reject") {
    items.push({
      id: "ocr",
      label: "문구 검수",
      status: "fail",
      message: "이미지 안의 문구가 기준을 통과하지 못했어요."
    });
  } else if (payload.requiresManualReview || ["manual_review", "unavailable", "retry_image", "retry_layout"].includes(ocrDecision)) {
    items.push({
      id: "ocr",
      label: "문구 검수",
      status: "warn",
      message: "사용 전에 이미지 안의 문구를 한 번 더 확인해주세요."
    });
  } else if (ocrDecision === "pass") {
    items.push({
      id: "ocr",
      label: "문구 검수",
      status: "pass",
      message: "이미지 안의 문구가 요청한 내용과 잘 맞아요."
    });
  }

  const compliance = payload.compliance;
  if (compliance?.status === "blocked") {
    items.push({
      id: "compliance",
      label: "광고 표현 확인",
      status: "fail",
      message: compliance.summary || "광고 표현 기준을 통과하지 못했어요."
    });
  } else if (compliance?.status === "rewritten" || compliance?.status === "needs_review") {
    items.push({
      id: "compliance",
      label: "광고 표현 확인",
      status: "warn",
      message: compliance.summary || "일부 표현은 사용 전에 한 번 더 확인해주세요."
    });
  } else if (compliance?.status === "pass") {
    items.push({
      id: "compliance",
      label: "광고 표현 확인",
      status: "pass",
      message: compliance.summary || "광고 표현 기준을 통과했어요."
    });
  }

  return items;
}
```

function snapshotStatus(snapshotKind: string, payload: Record<string, unknown>, currentQuestion: OptionQuestion | null): string {
  if (snapshotKind === "waiting_user_input" || currentQuestion) {
    return "waiting_user_input";
  }
  if (snapshotKind === "job_completed" || asRecord(payload.result_payload).status === "done") {
    return "done";
  }
  if (snapshotKind === "job_failed") {
    return "failed";
  }
  return "queued";
}

function copyCandidatesFrom(value: unknown): CopyOption[] {
  if (!Array.isArray(value)) {
    return [];
  }
  return value
    .map((candidate, index) => {
      const raw = asRecord(candidate);
      const headline = firstString(raw.headline, raw.title, raw.copy);
      if (!headline) {
        return null;
      }
      return {
        id: firstString(raw.id) || `copy_${index + 1}`,
